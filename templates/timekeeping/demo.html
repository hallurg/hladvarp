Readiness

Hvað er virkt, hvað er demo-only?

Til í núverandi kerfi

Starfsmenn, QR/starfsmannanúmer og API-aðgerðir fyrir inn/út stimplun eru þegar til í `starfsfolk`.

Demo-only hér

Mobile wizard, pair code, takkaflæði, history update og skýrslukort eru örugg demo-gögn.

Production eftir

Auth/session, device pairing, recovery, audit policy, admin approvals, exports og raunveruleg mobile prófun.

API staða

Stimpilklukka er komin með raunverulegan API-grunn.

Komið í API

Starfsmenn, dagleg mæting, símatæki, append-only atburðasaga, núverandi staða, leiðréttingarbeiðnir og samþykkt/höfnun stjórnanda eru komin sem `starfsfolk` API grunnur.

Sýnilegt demo hér

Þessi síða er enn örugg visual demo-síða. Hún sýnir flæðið, en notar ekki innskráða session eða raunverulegan síma í vafranum.

Næsta production-skref

Tengja auth/mobile UI við nýju API-endpointana, keyra migration í réttu production targeti og gera raunprófun á síma/spjaldtölvu áður en þetta verður launa/audit tilbúið.
